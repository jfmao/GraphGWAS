\bmhead{Data Availability}

Pan-UK Biobank summary statistics and LD reference matrices (used for
the cross-ancestry demonstration in Results~\ref{sec:cross_anc}) are
publicly available from the Pan-UKB project on Amazon S3 at
\url{s3://pan-ukb-us-east-1/} (no authentication required); see
\url{https://pan.ukbb.broadinstitute.org} for documentation. The 1000
Genomes Project high-coverage NYGC 30$\times$ release is available at
\url{https://www.internationalgenome.org/data-portal/data-collection/30x-grch38}.
The 1011 Yeast Genomes data are available from
\url{http://1002genomes.u-strasbg.fr/}. \emph{Arabidopsis thaliana}
1001 Genomes data are available from
\url{https://1001genomes.org/}. GENCODE~v47 annotations, GTEx~v8
eQTLs, STRING~v12 interactions, and ENCODE cCRE~v4 regulatory
elements are from their respective project portals. Pre-built
graph-database dumps in Neo4j~5.26 format (human 1KG with full
multi-omics annotations, 17~GB; yeast 1011 with SGD/GO
annotations, 0.5~GB) and all benchmark outputs (JSON~+~TSV),
per-locus Pan-UKB fine-mapping outputs, figure source data, and
simulation seeds are deposited on Zenodo (DOI to be assigned on
acceptance). The staging layout---with per-folder README files
documenting contents, file schemas, restore instructions and
SHA-256 manifest---is versioned alongside the source code under
\texttt{zenodo/} and is ready for upload via
\texttt{zenodo/prepare\_upload.sh}.

\bmhead{Code Availability}

GraphGWAS source code is available at
\url{https://github.com/jfmao/GraphGWAS} under the MIT licence. The
repository includes the Python package (\texttt{graphgwas}, 34~modules
covering import, association, fine-mapping, epistasis, heritability,
PRS, MR, Pan-UKB integration, and the \texttt{graphgwas} CLI), the
BGEN~+~graph hybrid reader, the sumstats-only fine-mapping entry
paths (\texttt{l1\_finemap\_from\_sumstats},
\texttt{hbp\_finemap\_from\_sumstats}), all benchmark scripts used in
this paper (\texttt{tests/benchmark\_*.py}), and a single-command
figure-regeneration pipeline
(\texttt{tests/generate\_paper\_figures.py}). A reproducibility guide
at \texttt{docs/REPRODUCIBILITY.md} documents regeneration of every
figure and table from scratch.
