# multispecies_leads/

The 692 lead loci across four species that drive the
heterogeneity-not-density meta-analysis (Table 1 in the paper).
Each species file lists every lead locus that survived the
trait-specific window-clustering filter, together with baseline-cache
and intervention-cache fine-mapping outputs and validation against
species-specific catalogues.

## Files

| File | Rows (incl. header) | Content |
|---|---|---|
| `cross_species_summary.tsv` | 5 | Top-line table: per-species GAFM CS=1 rate, HBP-tighter rate, validation rate (matches Sup Table S6). |
| `cross_species_report.md` | – | Narrative summary of the cross-species replication, identical to `results/multispecies_summary/cross_species_report.md` in the source repo. |
| `heterogeneity_intervention_report.md` | – | Per-species before/after intervention rates (matches Table 1). |
| `leads_yeast_1011.tsv` | 246 | 245 yeast leads × {trait, lead position, p-value, baseline / intervention HBP+GAFM CS sizes, validation hit}. |
| `leads_arabidopsis_1001g.tsv` | 55 | 54 Arabidopsis leads (analogous columns). |
| `leads_rice_3krg.tsv` | 73 | 72 rice IRRI leads (analogous columns). |
| `leads_human_chr22.tsv` | 322 | 321 Pan-UKB EUR leads on chr 22 (analogous columns; subset of `leads_human_genome_wide.tsv`). |
| `leads_human_genome_wide.tsv` | 322 | The genome-wide superset; identical lead set with all autosomes covered. |

## Schema (per-species lead TSVs)

```
species          STRING   yeast | arabidopsis | rice | human
trait            STRING   trait code (IRRI 3-letter for rice; phenotype name for others)
chr              STRING   chromosome
lead_pos         INT      lead variant position (1-based)
lead_variant_id  STRING   chr:pos:ref:alt
lead_pvalue      FLOAT    GWAS p-value at lead
n_variants_in_window  INT  size of the fine-mapping window
hbp_baseline_cs1     0/1   1 iff HBP CS=1 under the baseline cache
gafm_baseline_cs1    0/1   1 iff GAFM CS=1 under the baseline cache
hbp_baseline_pip     FLOAT lead PIP under HBP, baseline cache
gafm_baseline_pip    FLOAT lead PIP under GAFM, baseline cache
hbp_intervention_cs1 0/1   1 iff HBP CS=1 under the intervention cache (per-variant prior_score)
gafm_intervention_cs1 0/1  1 iff GAFM CS=1 under the intervention cache
validation_gene      STRING nearest validation-catalogue gene within 250 kb (or empty)
validation_distance_kb FLOAT distance in kb to the validation gene
validation_source    STRING species-specific catalogue (Bloom2015 | Peter2018 | AraGWAS | Ren2023 | GWASCatalog | LipidCanon)
```

## Reproducibility

These tables are regenerated by the per-species fine-mapping
pipelines in the source repository (`tests/benchmark_*.py` per species)
followed by `tests/multispecies_summary_report.py`.
The 250-kb validation windows match Methods §"Cross-species
fine-mapping protocol".
